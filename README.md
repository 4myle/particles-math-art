# Particles Math Art
An [egui](https://github.com/emilk/egui) visualization of particles forming amoeba like shapes. Original idea from a post on X by [@yuruyurau](https://x.com/yuruyurau/status/2100230050063024467). Try out the [live demo](https://4myle.github.io/particles-math-art/).

> **DISCLAIMER**: this application is a hobby project and should be used as such. Any other use it at your own risk. It is provided as-is and is not likely to be maintained regularly.
